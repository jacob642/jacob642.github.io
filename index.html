ML-KEM Encrypted Chat — Post-Quantum Key Exchange
Developer · C · OpenSSL · vendored PQClean (ML-KEM-768)

Built a client/server chat application in C using ML-KEM-768 (FIPS 203 post-quantum key encapsulation) to establish a shared secret, HKDF-SHA256 to derive a session key, and AES-256-GCM for authenticated message encryption. Includes a hand-rolled length-prefixed wire protocol with correct handling of partial TCP reads/writes, per-message nonce generation, and tamper detection verified against deliberately corrupted ciphertext.
